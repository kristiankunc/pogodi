https://github.com/astrochili/defold-annotations/releases/tag/1.13.1 - unzip and place in `.deps/defold-annotations`

## Running locally:

1. Follow setup on [pogodi server](https://github.com/kristiankunc/pogodi-coop-server)
2. Edit [game.properties](./game.properties) to point to your local pogodi server
3. Run 2 instances
4. Create a lobby/join

## Pre-commit hooks

This repo uses [prek](https://github.com/j178/prek) (`prek.toml`) to lint/format Lua and TOML.
